# GeoAtlas

A static geography website (black / green / blue theme). No build step needed to run it:

    python3 -m http.server   # then open http://localhost:8000

- **Home** – menu, hero globe, progress stats, country of the day
- **Explore** – draggable/zoomable globe; click a country (or search) for overview, history, languages and culture. Hand-written history for ~50 countries; others load a live Wikipedia summary.
- **Quiz** – capitals, flags, find-on-map, identify-on-map, mixed; filter by region and difficulty. **Practice mode** has free hints, no score, and repeats mistakes.
- **Achievements** – 16 badges and best scores, saved in `localStorage`.

`data/world.js` and `data/countries.js` are generated by `tools/build-data.js` (needs `world-atlas`, `world-countries`).
